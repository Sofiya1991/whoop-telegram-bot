# Privacy Policy — Sofiya WHOOP Bot

Last updated: September 23, 2026

## Overview

Sofiya WHOOP Bot is a personal application created for private use by the owner of the connected WHOOP account.

The application accesses WHOOP data only after explicit authorization by the WHOOP account owner.

## Data Access

The application may access the following WHOOP data:

- Recovery data
- Heart Rate Variability (HRV)
- Resting Heart Rate
- Sleep data and sleep stages
- Physiological cycle and Strain data
- Workout data
- Basic profile information
- Body measurements

## How Data Is Used

WHOOP data is used solely to provide personal health, fitness, recovery, sleep, and activity analytics to the account owner.

The application does not sell WHOOP data.

The application does not use WHOOP data for advertising.

The application does not share WHOOP data with third parties except for services explicitly configured by the account owner to provide the application's functionality.

## Data Storage

Authentication credentials and WHOOP access tokens are not stored in this public GitHub repository.

Any locally stored WHOOP data is used only for the personal functionality of the application.

## Data Access and Deletion

The WHOOP account owner may revoke the application's access to WHOOP data at any time.

Locally stored application data may also be deleted by the application owner.

## Contact

For questions regarding this privacy policy, please contact the application owner through the contact information provided in the WHOOP Developer application.
